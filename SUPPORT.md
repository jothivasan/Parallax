# Support

Thank you for using **Parallax**! We are committed to supporting our community of learners, educators, and engineers.

---

## How to Get Help

### 1. Documentation

Before opening an issue, check the authoritative documentation:

- [Development Setup Guide](docs/development/SETUP.md)
- [Troubleshooting Reference](docs/reference/TROUBLESHOOTING.md)
- [Language Compatibility Reference](docs/reference/LANGUAGE_COMPATIBILITY.md)
- [Deployment Guide (Static, Self-Hosting & Hybrid)](docs/deployment/DEPLOYMENT.md)

### 2. GitHub Issues

- **Bug Reports**: If you encounter unexpected execution traces, visualizer rendering glitches, or compiler crashes, please submit a report using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature Requests**: To suggest new language capabilities, visualizers, or curriculum lessons, use our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).

### 3. Security Inquiries

For security issues or sandbox escape disclosures, please follow the confidential disclosure process detailed in [SECURITY.md](SECURITY.md).
