# Parallax

Parallax is an open-source execution tracer and data structures and algorithms workbench for developers, students, and educators. The public landing page at `/` introduces the execution studio and lets visitors try a short example trace before opening `/studio`.

## Platform

Parallax is a web application. Browser execution uses dedicated workers and works on a static deployment. Native execution uses the configured backend toolchains. Runtimes share an execution trace format, with memory identities and language capabilities appropriate to each runtime.

## Landing page

Lead with the relationship between source code, state changes, and replay. Use working examples and route visitors to the studio, language reference, and open-source project. The application navigation gives learners access to the curriculum and coding challenges.
