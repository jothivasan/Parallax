# Parallax landing page

The public homepage uses an editorial workbench style. Paper off-white (#f8f8f1), dark green ink (#203632), and warm copper (#ac5132) connect display typography with the sunrise in the hero. Serif display headings alternate roman and italic. Controls use sans serif, with monospace reserved for source and program values.

The centered headline and engraved sunrise fill the first screen beneath the navigation. The horizon fades into the paper background before the Studio demonstration. The interactive studio preview directly below it shares one step selection across source, variables, and the data structure. Replay begins on user input. At narrow widths the preview panels stack in reading order.

## Execution Studio

The Studio shares the public palette, with paper and inset surfaces, dark green controls, and copper for the active step, workspace, and replay progress. Its compact serif title sits above sans-serif controls and a JetBrains Mono editor. The editor and workspace scroll independently on desktop, stack on tablets, and switch through Editor and Execution on mobile.

Run & Trace lives in the Studio header. Playback sits in the execution workspace and remains visible across Visualize, Inspect, Analyze, Console, and Sessions. Each workspace keeps its view as the trace advances. Editor options, runtime details, and layout presets open from their toolbar controls. Structure Canvas shows detected data structures using the same renderers across languages. Stack & Heap shows the current memory snapshot, and Inspect exposes language-specific pointers, owners, objects, collections, and lifecycle details in its tab row.

## Learning path and coding challenges

The practice pages share the Studio palette and navigation. Learn pairs a searchable curriculum with a lesson, complexity notes, and an editable starter. Challenges pairs the problem catalog with a prompt and solution editor. Edge cases and test details expand in place. On narrow screens, selecting an item moves focus to the lesson or problem.
